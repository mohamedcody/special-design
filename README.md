# Special Design

A responsive creative agency landing page built with plain HTML, CSS, and JavaScript. The template focuses on a clean single-page experience with interactive customization controls and smooth navigation between sections.

## Live Demo

Visit the live website: [Special Design](https://ahmedesam-415.github.io/Creat-Template-With-Html-Css-Js/)

## Preview

Open `index.html` in a browser to view the project locally.

## Features

- Responsive landing page layout
- Mobile navigation menu
- Customizable primary color
- Random landing-page background images
- Show or hide navigation bullets
- Settings persistence with `localStorage`
- Animated skills progress bars on scroll
- Image gallery popup viewer
- Smooth scrolling navigation
- Timeline, features, testimonials, and contact sections
- Font Awesome icons and Google Fonts integration

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome
- Google Fonts

## Getting Started

No package manager or build step is required.

1. Clone the repository:

	```bash
	git clone https://github.com/YOUR-USERNAME/special-design.git
	```

2. Open the project folder.
3. Open `index.html` directly in your browser, or serve the folder with a local development server.

For example, with VS Code, install the **Live Server** extension and open `index.html` with **Open with Live Server**.

## Customization

- Edit the page content and sections in `index.html`.
- Update the layout and theme styles in `Css/master.css`.
- Change interactions and stored settings in `Js/master.js`.
- Replace the images inside `Imgs/` with your own assets.
